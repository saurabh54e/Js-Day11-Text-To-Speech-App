🚀 Day 11/30 – Text to Speech Web App

Continuing my **30 Days JavaScript Challenge**, I built a **Text to Speech Web App** using **Vanilla JavaScript** and the **Web Speech API**.

Tech Used:

HTML
CSS
Vanilla JavaScript


Features:
Convert text into natural speech
Multiple voice selection
Supports different languages & accents
Simple and responsive UI
Instant speech playback
Easy-to-use interface

What I Learned:

Working with the Web Speech API
Using the SpeechSynthesis interface
Loading and managing available voices
Handling browser events dynamically
Building interactive JavaScript applications
Improving accessibility with text-to-speech

Next Improvements:

Pause, resume & stop speech controls
Adjust speech rate, pitch & volume
Save text and speech history
Download speech as an audio file
Dark mode support
